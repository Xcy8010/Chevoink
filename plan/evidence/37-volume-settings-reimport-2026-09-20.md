# 卷设置与历史重导归位

基线：`4b51f712cb9affcd5c1e7d8b0988dbc74ea3d157`。仅修改隔离工作树，原目录和私有 ZIP 不入库。

## 用户确认的行为

- 卷行悬停时，章节数量位置显示设置按钮；键盘和触屏同样可以打开。
- 卷设置通过自定义弹窗确认删除；仅剩一卷时不能删除。
- 用户明确选择保留章节、移动到相邻卷。优先追加到前卷；删除首卷时前插到后一卷，保留阅读顺序、章节 ID 和正文。
- 删除请求绑定卷 revision、目标卷 ID 和全部来源章节 revision。并发新增、修改章节或改变相邻目标时拒绝旧确认。
- 旧 Agent 无参数删除能力仍只允许空卷，不扩大工具授权。历史归档章节的外键记录保留，必要时归档卷而非删除历史正文。

## 导入差异

上轮只覆盖首次导入复用默认卷，未覆盖历史“空默认第一卷＋有正文的匹配第二卷”的重新导入。新建作品的创建、目录读取和结构规范化代码未发现默认 revision 被改变的证据。

另移除了空默认卷复用对 `revision=1` 的依赖：恢复或历史结构调整会改变技术版本号，不能据此判断卷是否可复用。仍限定唯一、无正文、无摘要、名称为默认第一卷，写入时使用读取到的真实 revision 做并发校验；自定义卷名或卷纲不被猜测覆盖。

此次对恰好两卷、首卷为无摘要空默认卷、唯一来源与后续正文卷匹配且实际选择章节的重导，归档空卷并将匹配卷移到第一位。原卷 ID 保留；归档与原卷序写入导入备份，恢复时还原。多卷、多来源或仅计划/元信息导入不触发该规则。生产历史数据不批量改写，修复随用户确认重导执行。
