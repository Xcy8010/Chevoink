# 简化一键导入与选择后按钮禁用修复

基线 7cba968。用户要求：像一键导出一样选择内容，底部仅取消/一键导入；修复勾选作品信息后无法导入。

## 实现与原因

旧界面将元数据勾选标为 dirty，footer 又以 dirty 禁用提交，要求用户先点单独保存预览，造成“按钮按不了”。本轮改为章节/计划/记忆/作品信息/封面选择，提交时统一保存选择、重取完整性证据、以新版本确认后提交。未选项只按绑定预览索引过滤原文并保留审计，不当作人工 review。后台完整性与所有权校验保留。

默认预览页底部只有取消、一键导入；取消关闭并放弃本地选择，持久任务保留。遇到问题的来源核对、编码与恢复工具收进详情。请求结果不确定先读状态，不能重复对旧索引应用选择。历史只读任务提交前重新核实入场确认并绑定原任务。

本站导出 ZIP 的计划原文保留为 plans；精确导出封面安全转码作为封面候选，不按正文送 OCR。未知附加文件及真正缺失正文仍核对，不能按目录名放过。

已有作品可先创建私有解析预览；最终按钮调用新的单次人类确认接口，再绑定任务与目标版本。保留旧两步 API 兼容，不把一次点击伪造成两次独立人工确认。服务端确认/提交仍校验最终授权。

审查补修：selection 返回未知时，重新查询若仍是原 revision/hash 保留用户勾选；若服务器版本不同，清空勾选并提示重新选择，不能默认扩大为全部。写入阶段关闭动作被阻止，避免“取消”等同于已中断在途提交的误解。

回归补修：尚未保存的勾选不能阻止查询未知请求结果或重新检查已变化的目标作品。重新检查空作品并绑定任务时保留同版本选择，避免取消单独保存按钮后出现恢复死路。
