## 实施内容

- 计划工具优先复用本次执行已读取的版本；显式旧 hash 与实际并发修改仍失败。持久任务仅使用已核验基线，不拿当前数据库版本冒充已观察版本。
- 场景数组完整解码；工具回执记录结构化失败码和字段路径，不记录私有参数值。待办维持拒绝回退/重复规则。
- 语音包下载、删除迁到创作区设置「语言包」，通过带来源标记的事件同步多个控制器，避免自身刷新覆盖下载完成状态。
- 普通 Agent 文件导入移交现有一键导入面板；作者选择内容并批准，Agent 不冒充已经导入。持久导入仍沿用持久批准流程。
- `cover_apply` 接受当前用户在当前任务上传的静态 PNG/JPG/WebP，校验附件归属、大小与像素上限，转换标准封面；发布仍受事务、取消和持久租约约束。
- 新增 `session_rename`、`account_credits`、`account_credit_history`、`account_novels`。查询限本人、分页、仅必要元信息；重命名只作用于当前窗口，自动标题不能覆盖已改名称。
- 两条已定位的上下文失败包含大量历史纯思考；原第二次压缩仍保留八个工具回合。现在释放已结束旧轮推理，压力下保留最新完整回合与所有未完成协议对；当前请求本身不可压缩时仍明确停止，不承诺无限上下文。
- 内置模型零倍率可配置限时免费、绝对到期时间和到期倍率。每个新操作按服务端时间解析价格并冻结，旧操作/回执不重算；普通免费和 BYOK 不变。模型菜单显示「限时免费」，到期刷新。供应商线路新增明确图片兼容选项标签。
- 使用现有模型 metadata，不新增数据库迁移。持久计费的既有 V2 入口门槛保持，不借本次促销绕过其价格协议要求。
