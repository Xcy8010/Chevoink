# 启创墨域隐私政策

> 第 2 版审阅稿，尚未生效。发布前须根据实际模型和供应商线路、受托关系、处理地区、数据留存设置和反馈流程补全待核项。本文中的审核措施和数据范围须与实际产品及运营过程一致。

### 一、个人信息处理者

启创墨域（Chevoink）由山东省淄博市启创联科网络科技工作室运营，所在地为山东省淄博市，官网为 [chevoink.chevolink.com](https://chevoink.chevolink.com)。本政策说明我们如何处理个人信息以及你如何行使权利。

### 二、我们处理的信息与用途

1. **注册和登录。** 根据所选方式处理手机号或邮箱、验证和登录信息，用于识别账号、验证和找回账号。使用密码时，服务端存储校验所需的散列值。注册时记录你确认的协议版本、时间及同意信息。昵称和头像由你主动填写或修改。
2. **创作和存储。** 为保存、编辑、同步和导出作品，处理你提交的稿件、素材、附图、提示词、会话和创作设置。使用 AI 功能时，处理完成任务所需的提示词、上下文、附件和生成结果。
3. **模型与工具。** 处理模型配置、任务状态、额度、用量和生成记录，以执行任务、展示用量和排查问题。外部自定义模型密钥经加密保存在服务端，启用后用于向所选提供方认证。
4. **社区和反馈。** 公开作品、帖子、评论和资料按你选择的范围展示。反馈、举报或申诉会处理你提交的问题说明、可选联系方式、必要证据、附件和排查所需的页面或客户端信息。
5. **会话和安全。** 使用 Cookie 和本地存储维持登录、记录必要偏好和保存本地草稿。处理必要的操作、请求和安全记录，用于故障排查和安全防护。清除本地数据可能需要重新登录，也可能清除仅保存在本设备的草稿。

我们根据提供所请求服务、履行法律义务及依法取得的同意等适用依据处理信息。可选功能在你使用时处理相应数据。基于同意进行的处理可按第六节撤回同意。

### 三、内容安全审核、举报与申诉

为判断和处置《用户服务协议》所列的违法内容，我们可能处理本次请求、判定所需的上下文或相关内容片段、拟生成或已生成结果的相关部分，以及定位处置所需的账号或任务编号、时间、审核结论及处置记录。我们按完成审核或处置所需的范围处理信息。

- **自动化判断。** Agent 和封面提示词功能在执行本次请求的模型调用中判断内容安全，模型可接收该任务所需的上下文。封面生图服务处理实际封面描述和画幅等生成参数。平台可依据该服务返回的内容安全结果停止本次生成。
- **人工复核与对外报告。** 收到举报、申诉或发现涉嫌违法内容时，获授权的人员可按需要复核相关片段和记录。依法需要报告时，仅向有权机关提供所需的相关信息。请避免提交无关个人信息、完整私稿、他人证件或模型密钥。
- **结果与申诉。** 自动化判断可能出错。如果内容被误拒绝或误处置，可按第八节申请复核，并提供任务编号和能够说明上下文的必要材料。

### 四、外部服务及数据接收情况

1. **短信验证。** 使用短信验证码时，手机号和发送所需模板参数由腾讯云计算（北京）有限责任公司提供的短信服务处理，用于验证码发送及核对送达结果。
2. **平台模型、封面和内容审核。** 完成任务所需的提示词、素材及上下文会传递给执行该请求的模型服务。当前协议载明内置模型接入云枢网关，并配置文本和生图备用服务。正式生效前须列明实际接收方、联系方式、数据种类、处理目的和方式、处理地区及适用的独立处理或委托关系。受托方应在约定范围内处理。提供给独立处理者或向境外提供个人信息的，我们依法履行告知、单独同意等适用义务。
3. **联网检索和网页读取。** 检索词或网址会提交给所用服务或目标网站。当前协议所列线路包括博查以及可能使用的搜狗、必应。请避免在查询中包含无关个人信息。
4. **自定义模型。** 你选用的提供方将接收完成请求所需的提示词、相关上下文、附件和认证信息。请在启用前了解所选提供方的规则及处理地区。
5. **企业微信客服。** 进入客服页面时适用微信客服的处理规则。我们处理你主动提供的内容、联系方式和必要附件，以受理、核查并答复请求。
6. **听书。** 语音合成所需的文字会发送给配置的服务。当前协议列明使用 Edge 语音合成。
7. **公开分享和法定披露。** 你主动发布的内容按所选范围公开。依法律规定或有权机关要求披露时，我们按适用规则核对依据和披露范围。

### 五、保存、删除和保护

我们按照实现目的所需的最短时间处理和保存个人信息，法律、行政法规另有规定的从其规定。账号存续期间保存维持账号及你选择保留的作品、会话和设置所需的信息。任务或操作为提供服务已保存的提示词、生图结果与拒绝回执、审核处置记录、举报证据、安全日志和备份，分别按适用的保存规则处理。

**待发布前补全**　按实际配置列明安全审核或处置记录、举报与申诉材料、请求日志和备份的保存期限或判定规则，区分平台与受托方、独立接收方。处理目的实现或期限届满后，依法删除或匿名化。依法需继续保存或备份暂无法单独删除的，仅用于保存和必要安全保护，按适用规则到期清理。

我们采用访问权限控制、登录校验和密钥加密等安全措施，按法律要求处理安全事件并通知受影响用户。

### 六、如何行使你的权利

你可以通过账号和作品页面查看、修改或导出资料。需要查阅、复制、补充、更正、删除、限制处理、撤回同意或注销账号时，可通过第八节联系。我们会按请求性质核验身份，依法办理并反馈。撤回可选功能的同意后，对应功能可能无法继续提供。

### 七、未成年人和政策更新

服务面向年满十八周岁的创作者。未成年人或监护人发现相关个人信息已经提交时，可通过第八节联系处理。涉及儿童个人信息，遵循适用的专门保护规则。

政策变更会通过官网、站内公告或适当方式通知。处理目的、方式、种类发生变化而需要重新取得同意的，我们依法另行办理。
