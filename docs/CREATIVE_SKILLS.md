# 创作技能、样章学习与子 Agent

当前内置技能包与资源路由契约为 **3.5.0**。新任务准入先持久化不可变资源，再冻结已启用版本；局部编辑以完整原请求、服务端冻结范围和当前检查为准。已保存任务与传统续跑保留旧 skill/router 版本和资源，历史 3.0.x/3.1.0 不改写。作者自建与第三方技能保留自身版本。

## 技能何时使用

技能是按需注入上下文的工作方法，不是模型训练，也不保证模型逐条服从。工具记录中没有 `skill_load` 不代表没使用技能：初始路由和阶段路由无需模型额外调用工具。

| 内置技能 | 主要场景/信号 |
| --- | --- |
| 中文网文项目定位 | 规划阶段：新书、题材、受众、卖点；Work 的 build 模式也支持 |
| 中文网文长篇规划 | 规划阶段：大纲、分卷、主支线、计划；Work 的 build 模式也支持 |
| 场景任务构建 | 场景/正文阶段：人物目标、阻力、选择与状态变化 |
| 中文网文自然正文 | 正文写作、续写、补写 |
| 人物声口与知识边界 | 人物、口吻、对白、关系、知识边界 |
| 情绪落地 | 情绪、痛苦、愤怒、悲伤、代入等 |
| 中文语言具体化 | AI味、机械、堆砌、虚浮、语言润色 |
| 文风连续性 | 风格割裂、前后节奏、叙事距离、语域 |
| 章节桥接 | 上下章承接与终态约束 |
| 证据化连续性审阅 | 人物、时间、地点及设定的连续性证据 |
| 近期结构去重 | 重复、套路、近期章节结构雷同 |

以上是场景摘要，不是每次必选清单。完整定义在 `api/lib/agent/skills/index.ts`。Router 3.5.0 仍遵守启用状态、阶段、意图、冲突和上下文名额；通常每阶段2–3项，手动/作者技能最多合计6项。弱场景信号可占一个专用名额，保留正文基础方法。纯错字、排版、打开、导出等操作不套创作模板；混合创作请求不会仅因出现这些词而整句被过滤。作者自建技能的模式和负触发规则保持不变。

长任务以成功工具回执推进技能阶段：章节准备→场景，场景建立→正文，正文写入→审阅，连续性检查报告错误→修订。同一执行片中每阶段最多解析一次，多章循环复用已解析说明，仅保留当前阶段提示；压缩移除提示后自动补回。失败/拒绝工具和纯机械操作不推进。提示切换发生在完整工具批次之后，不增加模型请求，不改变审批和工具权限。暂停恢复重新构造上下文，历史加载回执不会被覆盖。

技能面板统计当前作品保留的全部加载记录，按任务去重，包含自动路由、阶段加载和显式加载。历史没有记录的调用无法补算；“暂无加载记录”不是“从未使用”。加载记录不是文学质量或实际执行效果证据。

## 样章学习

技能面板和输入框「＋」可打开风格管理器，查看保存的文件、原文、学习进度、维度和逐字依据。保存样章本身不调用模型；须另行确认模型、供应商数据发送及计费，才开始分段分析。用户审核并启用规则后，后续任务自动获得当前作品的规则；不是训练模型，也不会强行改变正在运行任务的上下文。

历史画像若没有保存完整文件，明确标记需要重新上传。每作品仅启用一套规则。关闭、撤回和版本校验限制后续使用；已发送给供应商的请求不能撤回。中断不会自动重复计费请求，重试须重新确认。

## 子 Agent

主 Agent 可通过 `subagent_run` 调用已启用助手，或在确需委派且没有合适助手时通过 `subagent_delegate` 创建并执行。职责为调研、连续性、质量、设定四类；它们不是自动安装的四个助手。匹配触发条件后由主 Agent 决策调用，仍受审批、工具范围、并发和预算限制，不承诺必定触发。

输入框「＋」允许手动指定本作品已启用助手；选择只加入草稿，不自动执行。发送后主 Agent 通过现有工具执行并核验结果。已关闭、被删除或跨作品的选择被明确拒绝，不静默替换。子 Agent 不具备递归派生权限。尚未接入手动选择的持久协议会拒绝而非忽略请求。
