# 作品导入：实现状态与运行边界

[English](./NOVEL_IMPORT.en.md)

2026-09-13，本地实施中，尚未发布。对应 [32 号方案](../plan/32-作品一键导入与文档解析产品级实施方案.md)。**这份记录不是方案全部完成或生产验收证明。** 用户要求先完成代码、不使用服务器测试，本次未使用生产文件或服务器。

## 当前已接通的链路

- Work/IDE 作品菜单及移动菜单，在导出前进入同一导入面板。拖放限面板内，支持原文件选择、上传、解析、任务回查、取消、预览保存和提交回执。
- TXT/Markdown/DOCX/ZIP 的确定性解析；编码选择、来源警告、卷章重命名/排序/归卷、光标拆分。同源相邻章节可无损拼接，跨来源合并不伪造来源信息。
- 私有持久源文件和预览、所有者及当前作品校验、哈希验证、有限上传、解析租约、超时和取消。原文件下载使用认证接口，不暴露存储路径。
- 全解析放在独立 Worker，覆盖 Markdown AST、XML 和压缩包扫描；V8 堆、时间和正文规模有界。PDF/Mammoth 子进程由监督者管理生命周期。Node Worker 是资源隔离，不是操作系统安全沙箱。
- 当前仅允许**未发布且没有章节的作品**确认提交；已有空卷原样保留，新卷追加其后。单事务创建卷章并保存唯一回执，旧预览/来源/目标变化使批准失效，重复提交不生成重复章节。
- Agent `novel_import` 目前提供 `prepare/status`：仅接受本轮用户的真实附件，返回人工导入面板入口。它不自行解析收费、不写章节、不生成批准，也不得声称导入完成。
- 模型选择与预算校验模块已实现：基础模型 low 或输入框本次指定的自定义模型；不可用时不暗中换模型。**尚未接通 AI 调用、预算预留及账务结算**，当前确定性导入不调用模型、不扣模型额度。

## 开关与格式边界

总开关 `NOVEL_IMPORT_ENABLED` 默认关闭。未完成安全和产品验收前不要在生产开启。仅设置 `NOVEL_IMPORT_OVERWRITE_ENABLED` 也不能开启覆盖：代码中的覆盖验收门禁固定为 false；恢复、AI 能力同样关闭。

| 功能 | 当前状态 |
| --- | --- |
| TXT/MD/ZIP/DOCX → 空作品 | 本地端到端服务及界面代码；合成样本/隔离数据库回归，不等于三端人工验收 |
| PDF | 分页文字预览；完整性问题阻断提交，不把部分提取称为整书成功 |
| DOC、离线 OCR | 独立 Linux Docker Worker 原型及协议；真实容器、原生文件、中文准确率未测，业务入口不开放 |
| 已有章节覆盖/恢复 | 双确认界面、授权/归档/回执基础代码；全部写入链路、旧任务、公开快照兼容未完成，硬关闭 |
| 封面和正文图片 | 图片来源识别/警告不等于资源完整保存；候选选择、安全存储及完整预览未完成 |
| Agent 自动准备/持久提交审批 | 当前为只读人工交接；完整 prepare/commit/waiting 流程未完成 |
| ZIP/DOC 通过聊天附件上传 | 原有附件通道限制未放宽；用户可使用导入面板，不能声称聊天附件已支持全部格式 |
| 超大预览按需加载、来源排除 | 预览规模有上限；真正正文按需读取、显式排除与完整页图报告未完成 |

## 本地验证与安全边界

使用仓库固定 Node 22.23.2、独立本机 PostgreSQL 16、最小权限测试账号和合成作品。迁移前强制验证测试库名/回环地址/角色权限。测试库从全部迁移创建，未连接业务数据库。

回归覆盖越权、原文哈希、ZIP 路径/资源限制、编码、超长章节、迟到解析、取消、双击幂等、旧批准失效、事务冲突和零模型扣费。Worker 协议的 TypeScript/Python 测试与真实 DOC/OCR 容器验收分开记录。本地最终全仓 **2545/2545** 测试通过，类型/lint/覆盖率门槛/构建通过；Python协议11/11通过。范围、时钟测试夹具调整和未测项目见[阶段验证记录](../plan/evidence/32-novel-import-local-validation-2026-09-13.md)，不代表方案完整交付或远程CI通过。

### 存储与运维

- 原文件默认在项目外侧私有 `private-novel-imports` 目录，随机键、专用权限；不放入静态 public/uploads。备份时同步数据库与该目录，不能仅备份数据库。
- 未提交任务的来源和预览默认保留 7 天；提交/备份关联文件不由临时清理删除。保留 30 天备份记录**不等于当前支持用户恢复**。
- 清理仅消费精确孤立文件键，不扫描/递归删除整个存储目录。删除失败保留队列；监控失败计数。解析中的任务和有效租约不作为清理对象。
- 关闭总开关不删除任务，状态/原文件访问仍须鉴权，取消不得改动已提交结果。`NOVEL_IMPORT_MAINTENANCE_ENABLED` 可独立显式开启维护；未设置时跟随总开关。停用新导入但继续清理时应显式设为 `true`，不假定关闭功能后仍自动清理。
- 单用户滚动24小时最多10个任务、250 MiB上传（活动上传按50 MiB预留）；每任务最多64次预览修订，只保留最近两份。保存前获取数据库租约，并发旧请求不得先分配文件；垃圾积压100条时暂缓新预览。以上是初始保护上限，不是已压测吞吐量承诺。
- Nginx 模板仅对精确原文件路由提供 50 MiB 流式转发，其余 API 保持 40 MiB；没有把私有文件映射为静态目录。模板未在真实 Nginx 执行 `nginx -t`，部署前须验证，当前没有更新服务器配置。
- 迁移添加卷章归档字段并以活跃记录部分唯一索引替代旧全量唯一索引。禁止用 `prisma db push` 覆盖这些索引。尚未部署；先在隔离库验证后才评估生产迁移。
- 不应回滚到不理解归档的旧服务；启用覆盖前还需公开目录快照、全部读写作用域、后台任务代际隔离及恢复演练。
