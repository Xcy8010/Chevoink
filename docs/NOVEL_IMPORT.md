# 作品导入：实现状态与运行边界

[English](./NOVEL_IMPORT.en.md)

2026-09-14，按当前代码记录 [32 号方案](../plan/32-作品一键导入与文档解析产品级实施方案.md)。**不代表已经发布、生产启用或全部验收。** 已停止追加本地测试，后续等待远程 CI；native 同 SHA CI 仍待验证，Web/Windows/Android 真机交互未验收。本次未进行生产或服务器 QA，实际部署与验收证据由发布负责人补充。

## 当前实现

- Work/IDE 和移动菜单进入同一导入面板，支持上传、持久任务回查、取消、预览编辑、提交与恢复回执，显示原文件名和大小。
- TXT/Markdown/DOCX/ZIP 确定性解析及 PDF 分页文本报告支持编码选择、卷章重命名/排序/归卷、拆分和同源相邻章节无损合并。
- 来源报告保留稳定页、块、成员和图片标识；完整性问题须解决，或按支持的规则显式排除并填写原因。部分导入在回执中标识并保留报告，不能称为整书完整成功。
- 私有源文件、预览和规范化图片持久保存并校验哈希。长正文按章节和预览修订按需读取，结构保存不能把未加载正文写空。
- 解析离开 API 事件循环，资源、正文规模、截止时间及取消均有界。Node Worker 是资源隔离，不是操作系统安全沙箱；DOC/离线 OCR 使用独立受限 Docker native worker。

## 覆盖、公开快照与恢复

不再仅支持空作品。总开关开启后可导入空作品；已有章节还须开启覆盖开关，并完成共享人类双确认和具体预览批准。没有章节时保留已有空卷，新卷追加其后。

短事务内校验所有者、来源哈希、预览修订/哈希、目标版本及有效批准，使用作品写锁、活跃行条件、修订和实际影响行数保护。旧卷章保留原 ID 并归档，新卷章为**私有草稿**，不会自动发布。已有公开章节快照、公开阅读 ID、顺序和进度须保留；不能给公开快照查询笼统添加 active 过滤而使读者内容消失。作者目录、编辑、排序、导出和创作统计使用活跃结构，已发布统计/日期与创作统计分开。

导入推进稿件代际并使旧来源派生状态失效；并发写入和旧 Agent/后台结果不得写回归档来源。这些保护已进入实现，不等于所有历史写入路径已经完成远程验收。

提交保存唯一备份和持久回执，相同批准及幂等键重放不重复建章。恢复提供独立影响预览、人类确认及持久状态（可恢复、已恢复、过期、冲突），备份窗口为 30 天。恢复检查导入后基线和旧记录，归档导入行并恢复原 ID；后续编辑、发布或原版本漂移阻断恢复，不能强制覆盖。恢复回执独立保存，不替换原导入回执。关闭新导入不等于关闭已有任务的鉴权读取、取消或恢复。

## Agent 与聊天附件

`novel_import` 已注册 `prepare/status/commit` 持久运行链路，不再只是 prepare。prepare 只接受本轮用户真实附件，通过持久事件提供共享人工面板；commit 等待数据库中真实的人类批准，复核任务来源、当前操作、租约、策略和目标版本，再调用核心提交服务。

**模型参数、泛化 allow 或普通工具批准不能替代人类双确认，也不能生成导入批准。** waiting 状态、入口与回执可重放，重启不得重复提交；成功、取消或超时结束旧等待链路并要求后续输入。关闭面板本身不是取消。非持久执行入口拒绝 prepare/commit，不回退为无保护写入。

聊天附件已接受 DOC/ZIP，做扩展名及文件头检查；上传入口不解压、不运行 native 转换，`read_file` 引导专用导入流程。聊天上限仍为 PDF 10 MiB、DOC/ZIP 等非 PDF 5 MiB，与导入面板原文件 50 MiB 上限不同。

## 局部 AI 与预算

确定性解析不调用 AI、不扣模型额度。可选 AI 结构建议已接入：用户先核对模型与预算再确认，每次仅分析一个不超过 7000 字符的选中章节，不截断原文、不自动改写或应用正文。基础模型使用 low；自定义模型仅使用本次明确选择，配置或价格指纹变化须重新确认，不暗中换模型。

每任务最多 **4 次**持久建议请求，单次最多 **8000 输入 / 2000 输出 Token**；预算校验器另设任务上限 40000 输入 / 8000 输出 Token，四次及单次限制同时生效。失败和不确定请求不会因重放获得额外次数；同请求复用记录，进程丢失或供应商结果未知不自动重试付费调用。基础模型走现有额度预留及用量结算；自定义模型不扣平台模型额度，但供应商可能收费。取消或预览变化中止请求，迟到结果不得自动应用。

## 私有资源、公开封面与 outbox

原文件、预览、来源报告和提取图片使用所有者鉴权接口，默认位于项目外侧私有 `private-novel-imports`，不映射静态 public/uploads，不暴露内部路径。

**明确选用为作品封面是公开资源操作。** 用户选中并确认的规范化封面在提交后进入现有公开封面通道，不能承诺仍是私有附件；未选中的原文件及提取图片不会因此一起公开。候选须属于当前任务并通过哈希、类型和大小校验。

提交/恢复与副作用分离：持久 outbox 有界消费并保存唯一事件，更新目录/元数据/记忆/搜索刷新状态，处理封面落地和阅读记录元数据投影。失败保留 pending，维护轮次重试；不重做稿件提交、不启动收费记忆提取、不覆盖更新的用户封面。`effects.status = published` 指副作用事件已投递，**不是章节发布，也不是产品已部署**。界面通过回执或状态重放刷新。

## 部署与运维

| 配置 | 边界 |
| --- | --- |
| `NOVEL_IMPORT_ENABLED=true` | 新导入总开关，默认关闭；仅由部署负责人显式开启 |
| `NOVEL_IMPORT_OVERWRITE_ENABLED=true` | 与总开关同时开启才允许已有章节覆盖，不绕过确认和事务保护 |
| `NOVEL_IMPORT_NATIVE_ENABLED=true` | native 显式开关；当前保持关闭，等待验收 |
| `DOCUMENT_IMPORT_WORKER_IMAGE` / `DOCUMENT_IMPORT_WORKER_STAGING_ROOT` | native 镜像和隔离暂存配置，还须通过实际 readiness 探测 |
| `NOVEL_IMPORT_MAINTENANCE_ENABLED` | 未设置时跟随总开关；关闭新导入但继续清理/outbox 时须显式配置 |

DOC 能力依赖真实 worker readiness；PDF 文本解析不要求 native，扫描/OCR 则需要。已启用但不健康的 native 路径失败关闭，不把不完整回退当作成功。readiness 不等于质量或隔离验收。native 同 SHA CI（`.github/workflows/document-import-native.yml`）尚待验证，文档更新不会开启任何 flag。

数据库与私有文件目录须一起备份。未提交来源/预览默认保留 7 天；提交/备份关联资源及有效解析租约不由临时清理删除。清理只消费精确无引用键，失败留队，不递归删除共享根目录。

初始限制：单用户滚动 24 小时 10 个任务、250 MiB 上传（活动上传按 50 MiB 预留）；每任务最多 64 次预览修订，保留最近两份，垃圾积压 100 条时暂缓新预览。这是保护上限，不是压测承诺。Nginx 模板只对精确原文件路由提供 50 MiB 流式转发，其余 API 40 MiB；真实服务器配置未验证，本次不做服务器 QA。

部署完整迁移链，包括归档字段、活跃记录部分唯一索引、审批、回执和 outbox；禁止以 `prisma db push` 替代迁移覆盖索引。不得回滚到不理解归档的旧服务。迁移、私有存储权限、维护消费者和 flag 是独立部署检查项，代码实现不代表生产配置已经生效。
