# 内置模型线路与任务恢复

[English](./MODEL-ROUTING-AND-TASK-RECOVERY.en.md)

## 配置供应商线路

在管理端“模型管理”编辑内置文本模型，在主配置之外添加最多 7 条供应商线路。每条线路可使用不同供应商、模型和账号密钥，也可独立停用或移除。密钥加密保存，管理接口及审计不返回明文。保留已有主配置，无需重新填写已有密钥。

启用线路必须支持内置模型声明的推理强度、上下文窗口和图片输入能力。管理员应按真实供应商能力填写；本地不会付费探测这些能力。线路共用内置档位的用户费率，实际供应商及模型仍写入用量记录。

当前公开 Agent 循环及辅助文本调用轮流使用启用线路。收到 429、500、502、503、504 HTTP 失败响应且未报告正用量或部分用量时，在同档位内尝试其他线路，每次逻辑调用最多尝试 3 条线路、总计最多 360 秒，同时服从原请求更短的截止时间和取消信号。失败线路冷却至少 30 秒，尊重最长 5 分钟的 Retry-After。已开始的流式输出、传输结果不确定、正文截断和 BYOK 不自动重放。

失败调用账务不会伪装为免费：429 明确拒绝按既有规则处理；5xx 未知用量仍待核并保留相应预留，额度不足或供应商用量待核保护可能阻止进一步切换。所有线路不可用时保留进度并报告失败。持久执行协议 v1 仍使用冻结线路，不绕过其请求身份与回执限制。

## 继续与创作节奏

“继续”直接恢复当前会话的当前中止任务，不新增“请继续完成之前的任务”消息。从原始请求、已保存回复、工具回执和有界思考片段恢复；作品记忆和其他任务不构成新授权。没有旧合同的任务只从自己的原始请求重建合同。

自动续跑仍受原累计预算硬顶限制；作者手动继续可以授予现有规则允许的有限预算片，恢复时保留已授予额度而不再次截短。累计消耗、续跑次数与时间上限继续有效。

宽泛整书请求先交付方向、大纲和首批范围建议，等待作者明确指令后开始正文。该阶段在执行权限层限制正文工具与派生写作任务。明确指定章节或明确授权自主创作的请求照常执行其授权范围；普通问候和问答不授予作品写入权限。

## 工具检查

辅助模型请求明确发送与预留预算一致的输出上限。输出截断与断流分开反馈，不把部分检查当作通过。质量报告约束输出规模；持久质量检查最多追加一次逐字引文校正，不能删掉判断或改写正文来通过检查。

审批超时、缺少质量报告、改文后未重核连续性仍是有效拦截，不会通过伪造成功来提高工具成功率。

本说明描述代码行为；实际检查、CI 和部署状态以本次发布记录为准。
