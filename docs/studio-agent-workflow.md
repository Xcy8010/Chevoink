# 创作助手阶段边界

新任务的模糊整书创作意图先通过作者提问对齐方向。空新作品（包括首部隐藏占位与普通新建空作品）在说明初始化语境、收到同任务真实回答后保存书名、简介与标签。明确要求代选并初始化时直接执行。已设元信息或已有正文的作品只对齐方向，保留已有内容，不产生初始化保存义务；明确重新初始化除外。回答只讨论、先别初始化或对方向都不满意时如实结束。

完整初始化一次提交书名、简介与标签；缺项调用不会部分保存，可补齐后重试。解释初始化、引用相关文字或明确拒绝初始化不产生保存义务。重新准备相同任务目标时，已创建尾卷的决定、前章版本与活动卷身份必须一致，才继承原绑定；不匹配拒绝创建替代卷。

完整初始化的完成检查同时核对当前保存值与同一任务真实成功写入凭据，普通回复不能充当保存证明。仅改标签或简介不要求重写三项。缺少封面须如实说明并询问是否补做，不会自动开启收费生成。初始化和大纲交付后用普通作者语言简短询问下一阶段并结束本轮，后续建议不等于新授权。过程摘要不向作者暴露工具参数、内部编号或原始推理。

新任务建卷使用 `volume_create`，取得真实卷编号后再写入章节或在原授权内迁移。仅写下一章的尾卷能力仍要求同任务准备决定、真实前章版本与精确收束证据；创建出的卷身份持久绑定该目标，同一决定重放复用，不能扩大为任意目录移动。旧冻结协议保留历史 `chapter_create.newVolume` 兼容。新增规划模式写入能力仅由新任务准入的服务端协议开启，旧任务不自动升级。

计划读取与保存回执携带正文版本和内容/关联语义版本。服务端可以复用本次真实读取的语义版本，或经过完整目标版本校验的持久化冻结基线；显式过期版本仍拒绝，父大纲版本不会自动推进。

本地定向单元测试不等于 PostgreSQL 集成或发布验收；原同提交完整 CI 保留四闸、数据库零跳过、Agent eval 与依赖审计。
