# 本地模型与中转站

Chevoink 支持由提供模型的电脑主动连接云端的连接器。官网模型设置中可选择本机 OpenAI 兼容中转、LM Studio 或 Ollama。云端不直接访问用户电脑的回环或内网，现有公网接口校验保持原样。

1. 启动本机模型服务，填写真实模型 ID、地址和上下文窗口，选择对应本地供应商并保存连接配置。首次保存不发送模型请求；模型保持停用。
2. 在提供模型的电脑安装 Node.js 22，下载页面提供的 `chevoink-local-connector.mjs` 和 `chevoink-connector.local.json`。如需上游密钥，仅编辑配置文件的 `apiKey`；无认证服务保持空字符串。
3. 在这两个文件所在目录执行 `node chevoink-local-connector.mjs chevoink-connector.local.json`。终端持续运行；Ctrl+C 停止。连接器没有监听端口、任意代理或 shell 能力。
4. 回到官网，编辑本模型、启用后点击“校验并保存”。该操作最多发送7次少量合成请求，上游可能收费；连接测试不使用作品正文。HTTP成功不等于能力通过，原生工具和图片须返回可核验结果。未确认的能力保持未知。

服务地址只接受明确的本机或 RFC1918 IP（如 `127.0.0.1`、`::1`、`192.168.x.x`）、HTTP/HTTPS和自定义端口；不接受重定向、URL凭据、云元数据、任意域名或公开地址。本机中转站通常使用 `/v1`；Ollama使用原生 `/api/chat`，由连接器设置 `num_ctx` 和输出上限。HTTPS仍验证证书，不放宽TLS。

模型密钥只从本地文件发送到固定的本地目标。云端保存的是独立连接凭据，不能用来登录账号或执行工具；连接器只处理对应模型。配置文件含此凭据，应限制访问，不提交Git或分享。删除模型、账号封禁或会话版本吊销会阻止继续使用。修改服务地址/模型身份时新建配置，不为原任务偷换路由。丢失连接配置时删除该配置并重新配对。

主循环、复核、连续性与其他辅助文字请求共享连接通道；现有工具权限、正文版本、任务恢复与用量证据继续由云端执行。工具未验证的本地模型不能执行Agent工具请求。Ollama原生适配只映射明确支持的参数；不支持的强制工具选择/响应格式等返回明确拒绝，不伪造工具调用或降级检查。非思考检查仍要求有依据的关闭思考能力；不能确认的模型不能冒充已完成检查。

连接器支持流式文字、工具与实际思考通道透传；真实用量由模型响应提供。平台沿用自定义模型的额度豁免政策，上游现金成本仍可能发生，缺失用量不补零。断连、取消、响应过大和未知结果不自动重发模型请求。单个模型同时处理一个请求；当前瞬态传输由单个API进程持有，不是跨进程消息队列。

**使用边界：** 模型所在电脑必须在线。家中电脑关机后，可以继续使用云端开发与构建，或选择公网模型；家中模型不能继续推理。作品、工具和任务仍由云端处理，这不是完整离线创作或全文不出设备。真实模型、机型、长篇速度和文学质量需要独立验收，离线协议测试不能替代。
